# Input data

These files are not committed. See the Reproducing section of the top-level README for
the two download commands, and download `nmppdb.smi` manually from
https://nmppdb.com.ng/download in SMILES format.

| File | Description |
|---|---|
| `nmppdb.smi` | NMPP-DB v1.0 compound library, SMILES format |
| `zinc250k.csv` | ZINC 250k drug-like subset |
| `EGFR_compounds.csv` | ChEMBL EGFR bioactivity set via TeachOpenCADD |
